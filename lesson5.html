EXCEL ESSENTIALS / LESSON 05

Make the numbers meaningful

A clear chart helps someone understand your work at a glance. Finish your budget, then see how much you’ve learned.

12 minute lessonLesson 5 of 5Read · Try · Reflect

Learning objective

By the end of this lesson

Choose a useful chart and complete a five-question knowledge check.

Choose a chart with a purpose

We want to compare four categories of supplies. A bar or column chart makes that comparison easy. A line chart is more useful when the question is about change over time.

  1. Clear any filters in your workshop data.
  2. Copy the Item and Line total values into a small, adjacent two-column summary on a new worksheet. Include all four supplies and the two headings. Use Paste Values for the totals so Excel copies results rather than relative formulas.
  3. Select that summary, then choose a bar or column chart from the Insert tab. Chart controls vary by Excel version.
  4. Use the title Workshop supply costs (INR). Add value labels so readers can see the amounts.
  5. Check that the chart contains four supplies and excludes the overall total.

For a bar chart, start the value axis at zero so the bar lengths represent the differences fairly. Use a descriptive title, legible text, and a simple color scheme. If your Excel version supports chart alt text, add a description of the comparison and the main finding.

The takeaway

Notebooks cost ₹108.00, just over half of the ₹207.00 budget. A useful chart supports a statement like this with readable values.

Finish with a quick review

Save the finished workbook as an .xlsx file so formulas, formatting, and the chart are retained. Before sharing it, check your headings, formulas, number formats, and chart labels. Keep a readable data table alongside the chart.

You can use the completed budget as a practice artifact. To make it your own, replace the example supplies with a real project and explain the decision your chart helps someone make.
