EXCEL ESSENTIALS / LESSON 01

Meet your spreadsheet

A spreadsheet is a place to turn everyday information into something useful. Let’s start with the grid.

6 minute lessonLesson 1 of 5Read · Try · Reflect

Learning objective

By the end of this lesson

Find a cell, recognize a range, and save a workbook.

Find your way around

Imagine you are planning a community workshop. You need to track supplies, quantities, and costs. Excel gives each piece of information its own place in a grid.

A workbook is the file you save. Inside it, a worksheet is one sheet of cells. Use the sheet tabs to move between worksheets in the same workbook.

  • Columns run vertically and use letters: A, B, C.
  • Rows run horizontally and use numbers: 1, 2, 3.
  • A cell is where a column and row meet. B3 is in column B, row 3.
  • A range is a group of cells. A2:C4 includes every cell from A2 to C4.
A small vocabulary that goes a long way
TermMeaningExample
WorkbookThe complete spreadsheet fileWorkshop budget.xlsx
WorksheetOne sheet inside a workbookSupplies
CellOne location in the gridB3
RangeA group of cellsA2:C4

Make your first workbook

  1. Open Excel and create a blank workbook.
  2. Select A1 and type Item. Press Tab to move to B1.
  3. Type Quantity in B1 and Unit cost (INR) in C1.
  4. Select A2 and type Notebooks. Press Enter to move down.
  5. Save the workbook with a meaningful name, such as Workshop budget.xlsx.

You can use the arrow keys to move between cells. The name box, near the formula bar, shows the selected cell’s address. Type B3 into that box to jump directly to B3.

Build a useful habit

Save after each meaningful change. Use Excel’s Save command; if AutoSave is available, confirm that the file is stored in the location you expect.

YOUR TURN

Make it stick

How many cells are in B2:D4? Name the top-left and bottom-right cells.

Check your thinking

There are 9 cells: 3 columns × 3 rows. B2 is the top-left cell, and D4 is the bottom-right cell.
